itsRide Mobile Rate & Quote Calculator V1.2

WHAT CHANGED
- Distance Pricing now requires FROM address, TO address, and One-Way Distance (KM).
- Manual Base Fare now requires FROM and TO addresses.
- 0 km no longer produces a base fare.
- Round Trip doubles the one-way transportation amount.
- Swap From / To button added.
- Customer PNG/JPG shows FROM and TO addresses; kilometres remain internal.
- 171 official routes and existing official-route prices are preserved.
- Service worker updated to reduce stale-version caching after GitHub updates.

GITHUB UPDATE
1. Open the existing itsride-mobile-quote repository.
2. Upload/replace ALL files from this V1.2 package in the repository root.
3. Commit changes to main.
4. Wait for GitHub Pages deployment.
5. Open https://itsridelimo.github.io/itsride-mobile-quote/
6. Refresh once. If an older installed Home Screen version remains, close it and reopen after the web page shows V1.2.

PRICING WORKFLOW
Official Route Rate: select saved route and vehicle.
Distance Pricing: enter FROM, TO and one-way km.
Manual Base Fare: enter FROM, TO and negotiated one-way fare.
