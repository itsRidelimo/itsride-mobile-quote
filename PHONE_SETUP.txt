itsRide Mobile Rate & Quote Calculator V1.3

WHAT CHANGED
- Customer pricing line renamed from Transportation to Base Fare.
- Professional Quote Reference added automatically.
- Optional Service Date and Pickup Time added.
- Optional Passenger and Luggage counts added.
- Optional Flight / Client Reference added.
- Quote preview, WhatsApp text, PNG and JPG now include professional trip details.
- Distance Pricing still requires FROM, TO and one-way KM.
- Manual Base Fare requires FROM, TO and a negotiated one-way base fare.
- 0 km cannot generate a distance fare.
- Round Trip doubles the one-way base fare.
- 171 official routes and official-route prices are preserved.
- Airport fee, Meet & Greet, waiting, tolls, parking, gratuity and HST remain separate line items when used.

GITHUB UPDATE
1. Open the existing itsride-mobile-quote repository.
2. Upload/replace ALL files from this V1.3 package in the repository root.
3. Commit changes to main.
4. Wait for GitHub Pages deployment.
5. Open https://itsridelimo.github.io/itsride-mobile-quote/
6. Refresh once. If an older Home Screen version remains, close it and reopen after the web page shows V1.3.

PRICING WORKFLOW

Distance Pricing: enter FROM, TO and one-way km.
Manual Base Fare: enter FROM, TO and negotiated one-way fare.
